# Portfolio Studio — Premium Template v3

This package is a reusable, client-ready foundation covering public web, user web app, user Android, admin website, admin web app, admin Android and backend.

## Included
- Typed shared contracts and validation
- Deterministic demo/mock providers
- Auth + password reset contract + RBAC
- CRUD/search/filter/pagination patterns
- Loading/empty/error states
- Provider interfaces for OTP/email/SMS/payment/OAuth/storage/maps/AI
- Prisma persistence model and seed/test scaffolding
- Compose user/admin flows with ViewModel state
- Acceptance checklist and integration contracts

## Local development credentials
- User: `user@portfolio-studio.local` / `LocalUser123!`
- Admin: `admin@portfolio-studio.local` / `LocalAdmin123!`

## Domain modules
- projects
- case-studies
- leads

Real third-party credentials and client-specific provider accounts are intentionally not embedded. Replace mock providers through their interfaces and environment variables.
