## Deployment notes

- Vercel permits at most 25 Git-linked projects for one repository. The catalog and templates 01–24 are linked to GitHub; templates 25–50 were deployed from the same `main` source using direct Git-source deployments. Those 26 projects need a redeploy after future code changes.
- The catalog’s Admin panel saves display-name preferences in the current browser only (`localStorage`). There is no hosted database, authentication, or global publish/update mechanism, so local edits do not affect other visitors.
- Android source is included in the public repository; APK generation is not part of this release.
